Overview
What SketchScreen is and how it fits into the application

SketchScreen is the main drawing component for a CAD/CAM application built with React Native, @shopify/react-native-skia for canvas rendering, and react-native-reanimated for gesture-driven shared values. It manages the complete lifecycle of 2D shape drawing, editing, snapping, layering, and extrusion to 3D.

ℹ The component receives a single optional prop: navigation — used to navigate to ToThreeDScreen when the user confirms an extrusion operation.
Component Props
PropTypeRequiredDescription
navigationobjectoptionalReact Navigation prop. Used to call navigation.navigate("ToThreeDScreen", { shape2D }) when extruding a shape.
Key Dependencies

GPU-accelerated 2D canvas. Used for Canvas, Path, Circle, Group, Skia.Path.Make() and all shape rendering.
react-native-reanimated

Provides useSharedValue, useDerivedValue, runOnJS, withSpring. All gesture state lives in shared values so the worklet thread can access it without crossing the JS bridge.
react-native-gesture-handler

react-native core
UI
Animated, Modal, ScrollView, TextInput, Switch, KeyboardAvoidingView used across the toolbar, panels, and modals.
02
Architecture
Thread model and data flow between UI thread, worklet thread, and JS thread
⚠ The component uses a dual-thread model. Gesture handlers run on the Reanimated worklet thread for 60+ fps. They read SharedValues directly and call back to the JS thread via runOnJS() for state mutations.
Thread Flow
User Touch Event
Raw touch enters via GestureDetector wrapping the Skia Canvas.
Worklet Thread — Gesture Handler
Pan / Tap gestures (tagged "worklet") convert screen coords to canvas coords using current zoomSV. Snap is applied via snapPoint() worklet. SharedValues (x0SV, y1SV, draggingSV…) are updated instantly, no JS bridge.
runOnJS() — Cross-thread Dispatch
At key moments (end of drag, tap, poly segment commit), stable JS callbacks (sEnd, sTap, sMoveEnd…) are called via runOnJS(). These are stable useRef wrappers that delegate to mutable cb.current.* handlers to always see fresh state.
JS Thread — State Update
setShapes(), setSelectedId(), commit() etc. run on the JS thread and trigger React re-renders.
Skia Canvas Re-render
Derived values (livePath, ghostPath…) update the canvas on the GPU thread via useDerivedValue, completely bypassing React diffing for live drawing previews.
Stable Callback Pattern
// Problem: runOnJS() captures stale closures
// Solution: stable useRef wrapper → mutable cb.current dispatch

// 1. Mutable handler (always current closure)
onTapRef.current = (rx, ry) => { ... /* sees latest state */ };

// 2. Stable cb object
cb.current.tap = (x, y) => onTapRef.current(x, y);

// 3. Stable runOnJS wrapper (created once, never recreated)
const sTap = useRef((x, y) => cb.current.tap(x, y)).current;

// 4. Used safely in worklet
runOnJS(sTap)(canvasX, canvasY);

Core Callbacks
Main event handlers wired through the cb.current dispatch pattern
commit(shape)

The central shape-commit function. Wraps shape creation with ID generation, layer assignment, and cleanup.

Validate
Returns early if shape is null/undefined.
Assign ID
Generates shape_{timestamp}_{random9} unique ID. Adds layer: activeLayer.
Filter defaults
Removes any existing DEFAULT_* preview shapes before appending the committed shape.
Update state
Calls setShapes, setSelectedId(id), clears status text, auto-close target, and arc HUD data.
onEndRef.current(rx, ry)

Called when a drawing drag ends. Routes by toolSV.value:

ToolBehavior
FREEHANDCommits accumulated freehandRef points as a FREEHAND shape if ≥3 points.
ARC (step 1)Stores center + P1 in arcStepRef. Shows "Tap to set arc endpoint" status.
ARC (step 2)Commits full ARC shape with center, p1, p2.
LINE, RECT, CIRCLE…Applies ortho constraint if enabled. Checks minimum size guard. Commits the shape via commit().
SELECT, MOVE, POLYLINE, SPLINE, ERASERExits early — these tools handle their own commit logic.
onTapRef.current(rx, ry)

Handles single tap events. Order matters — edit tool handlers fire before SELECT to prevent accidental deselection.

ToolAction
COPYCalls handleCopyPlace(pt.x, pt.y).
TRIMTwo-tap workflow: first tap selects boundary, second tap trims segment.
EXTENDTwo-tap workflow: first tap selects boundary, second tap extends target line to it.
FILLET / CHAMFERTwo-tap workflow: first tap selects first line, second tap applies operation between both selected lines.
SELECT / MOVEHit-tests all shapes from back to front, sets selectedId to topmost match.
ERASERRemoves all shapes that pass hit test at tap point.
onPolySegEnd(x1, y1, x2, y2)

Called when a polyline segment drag ends. Handles both line and arc segment modes.

ScenarioAction
Auto-close (endpoint near start)Commits the completed closed shape and resets all poly state.
Arc modeComputes arc segment via computeArcSegment(), stores { arcTo, cx, cy, radius, startA, sweepDeg } in the points array.
Line modeAppends plain {x, y} point to the accumulating array.

Gesture System
Three gesture recognizers composed into one exclusive gesture tree
Gesture Tree
Gesture.Exclusive(
  Gesture.Simultaneous(dblG, tapG),  // double tap wins over single tap
  panG                                // fallback for drags
)
ℹ dblG and tapG run simultaneously so the double-tap can intercept before the single-tap fires. panG only activates after minDistance(1) threshold.
panG — Gesture.Pan()
HandlerKey Actions
onBeginConverts screen → canvas coords. Routes to tool-specific begin logic: MOVE (start tracking + sMoveBegin), FREEHAND (first point), POLYLINE/SPLINE (set start or continue), STRETCH (record rubber-band origin), all others (snap + set x0/y0).
onUpdateUpdates x1SV/y1SV (and coordXSV/Y) for live preview. MOVE updates moveDx/Dy. FREEHAND appends point. STRETCH updates rubber-band. Throttled auto-close/arc HUD updates via bit-masking (fc & 0xF) === 0.
onEndMOVE: calls sMoveEnd(dx, dy). FREEHAND: calls sEnd. STRETCH: dispatches to sStretchWindow or sStretchApply based on stretchPhaseSV. POLYLINE/SPLINE arc-mode: commits arc segment. Others: calls sEnd(pt.x, pt.y).
tapG — Gesture.Tap() (single)

Max duration 250ms. For POLYLINE/SPLINE in arc mode: commits arc segment via sPolySegEnd. Otherwise calls sTap(canvasX, canvasY) which routes to onTapRef.current.

dblG — Gesture.Tap().numberOfTaps(2)

Max duration 400ms, 2 taps. For POLYLINE/SPLINE: calls sFinish() to commit the open polyline. For other tools: calls sDblTap which enters inline edit mode on the tapped shape.

Coordinate Conversion
// Screen pixel → canvas unit (applied in every gesture handler)
const canvasX = (e.x - width / 2) / zoomSV.value;
const canvasY = (e.y - canvasHeight / 2) / zoomSV.value;

The canvas origin (0,0) is at the screen center. Skia canvas uses the same transform: translateX: width/2, translateY: canvasHeight/2, scaleX: zoom, scaleY: zoom.

19
Data Flow
How a shape goes from touch to committed state
Drawing a LINE — full lifecycle
Tool selected
selectTool("LINE") → sets activeTool, syncs toolSV, resets poly state, injects default LINE preview shape.
Finger down (panG.onBegin)
Worklet thread: screen → canvas → snap. Sets x0SV, y0SV, x1SV, y1SV. Sets draggingSV = true.
Finger move (panG.onUpdate)
Worklet: snaps cursor, updates x1SV, y1SV. LivePreview useDerivedValue rebuilds line path → GPU renders instantly. Throttled auto-close check.
Finger up (panG.onEnd)
Worklet: snaps final point. Calls runOnJS(sEnd)(pt.x, pt.y).
sEnd → onEndRef.current
JS thread: reads x0SV.value for start, applies ortho constraint if needed, checks minimum size (d < 4). Calls commit({ type:"LINE", p1, p2 }).
commit()
Assigns ID, adds to shapes (replacing DEFAULT_ preview), sets selectedId. React re-renders → RenderShape renders the final shape. kpSV updated for future snap targets.

Extrude Pipeline
How a 2D shape becomes a 3D extrusion payload
◈ The extrude button only appears when isClosedGeometry(selectedShape) returns true. Extrudable types: RECTANGLE, CIRCLE, ELLIPSE, POLYGON, TRIANGLE, STAR, SLOT, and closed POLYLINE/SPLINE.
Extrude Flow
ExtrudeButton pressed
handleExtrudePress(shape) → sets extrudeShape state → shows ExtrudeModal.
User configures in ExtrudeModal
Selects mode (Solid/Shell/Taper), sets depth (mm), previews JSON payload.
"Send to 3D" pressed
handleExtrudeConfirm(shape, depth, mode) builds shape2D payload via getShapePayload(shape).
Navigation
navigation.navigate("ToThreeDScreen", { shape2D }). If navigation is unavailable, logs to console + shows alert (dev fallback).
