CustomGCodeParser - Complete Documentation

Overview

CustomGCodeParser is a single-class CNC GCode/MCode parser written in pure JavaScript with NO external dependencies. It's designed specifically for CNC lathe operations and provides comprehensive parsing, validation, and analysis of GCode programs.

Key Features

✅ Single Class - Entire parser in one class
✅ No Dependencies - Pure JavaScript, no libraries
✅ Fast - Efficient parsing and calculations
✅ Complete - Supports 50+ G and M codes
✅ Production Ready - Error handling and validation
✅ Easy to Use - Simple API, intuitive methods
✅ Flexible - Works in Node.js and browsers

Installation

Node.js

javascript
const CustomGCodeParser = require('./CustomGCodeParser.js');

Browser

html
<script src="CustomGCodeParser.js"></script>

Quick Start (30 seconds)

javascript
// Create parser
const parser = new CustomGCodeParser();

// Parse GCode
const code = `
G21 G90
M3 S1000
G0 X10 Z5
G1 X20 Z-10 F100
M5
`;

const report = parser.parse(code);

// Get results
console.log(report.success);        // true
console.log(report.commands.length); // 5
console.log(report.stats);          // Statistics

API Reference

Constructor

javascript
const parser = new CustomGCodeParser();

Creates a new parser instance with default state.

Main Methods

parse(gcodeText)

Parse complete GCode program and return report.

javascript
const report = parser.parse(gcodeString);
// Returns: {success, commands, errors, warnings, state, stats}

parseLine(line)

Parse single line of GCode.

javascript
parser.parseLine('G0 X10 Z5');
// Updates internal state and commands array

reset()

Reset parser state and clear all commands.

javascript
parser.reset();

Data Access Methods

getToolpath()

Get only motion commands (RAPID, LINEAR, ARC).

javascript
const toolpath = parser.getToolpath();
// Returns: Array of motion commands

getSpindleEvents()

Get spindle control commands.

javascript
const spindleCommands = parser.getSpindleEvents();
// Returns: Array of SPINDLE and SPINDLE_OFF commands

getToolChanges()

Get tool change commands.

javascript
const toolChanges = parser.getToolChanges();
// Returns: Array of TOOL_CHANGE commands

getCommandsByType(type)

Get commands by type.

javascript
const rapids = parser.getCommandsByType('RAPID');
const arcs = parser.getCommandsByType('ARC');

Export Methods

toJSON()

Export data as JSON object.

javascript
const json = parser.toJSON();
// Returns: {commands, state, stats, errors, warnings}

toString()

Export formatted text report.

javascript
const report = parser.toString();
console.log(report);

Machine State

The parser maintains complete machine state:

javascript
parser.state = {
  position: {x: 0, z: 0},           // Current tool position
  feedRate: 100,                    // Current F value
  feedMode: 'G94',                  // G94 or G95
  units: 'G21',                     // G20 (inches) or G21 (mm)
  distanceMode: 'G90',              // G90 (absolute) or G91 (incremental)
  motionMode: 'G1',                 // G0, G1, G2, or G3
  plane: 'G18',                     // G18 (XZ), G19 (YZ), G20 (XY)
  tool: 0,                          // Current tool number
  spindle: {
    on: true,
    speed: 1000,
    direction: 'CW'
  },
  coolant: {
    on: true,
    type: 'flood'
  }
}

Usage Examples

Example 1: Basic Program

javascript
const parser = new CustomGCodeParser();

const gcode = `
G21 G90         ; Metric, absolute
M3 S1000        ; Spindle 1000 RPM
G0 X10 Z5       ; Rapid
G1 X20 Z-10 F100 ; Feed
M5              ; Stop
`;

const report = parser.parse(gcode);

if (report.success) {
  console.log('✓ Program valid');
  console.log(`Commands: ${report.commands.length}`);
} else {
  console.log('✗ Errors:');
  report.errors.forEach(e => console.log(`  ${e}`));
}

Example 2: Arc Motion

javascript
const parser = new CustomGCodeParser();

const gcode = `
G21 G90
G0 X0 Z0
G2 X10 Z10 R7.071    ; Radius mode
G3 X20 Z20 I5 K5     ; Offset mode
`;

const report = parser.parse(gcode);

report.commands.forEach(cmd => {
  if (cmd.type === 'ARC') {
    console.log(`${cmd.code}: Center (${cmd.center.x}, ${cmd.center.z})`);
  }
});

Example 3: Multi-Tool Program

javascript
const parser = new CustomGCodeParser();

const gcode = `
G21 G90
T1 M6
M3 S1000
G1 X20 Z-10 F100
T2 M6
M3 S1500
G1 X25 Z-15 F50
M30
`;

const report = parser.parse(gcode);

// Get tool changes
const toolChanges = parser.getToolChanges();
console.log(`Tool changes: ${toolChanges.length}`);

// Get motion commands
const toolpath = parser.getToolpath();
console.log(`Rapid/Linear/Arc: ${toolpath.length}`);

Example 4: Incremental Mode

javascript
const parser = new CustomGCodeParser();

const gcode = `
G91         ; Incremental
G0 X10 Z5   ; Move +10, +5
G1 X5 Z-2 F100  ; Move +5, -2
G90         ; Back to absolute
`;

const report = parser.parse(gcode);
console.log('Final position:', report.state.position);

Example 5: Error Handling

javascript
const parser = new CustomGCodeParser();

const badCode = `
G0 X0 Z0
G2 X10 Z10      ; Missing arc center!
`;

const report = parser.parse(badCode);

if (!report.success) {
  report.errors.forEach(error => {
    console.error(error);
  });
}

Tips & Best Practices

1. Always Check Success

javascript
const report = parser.parse(gcode);
if (!report.success) {
  // Handle errors
}

2. Use getToolpath() for Visualization

javascript
const toolpath = parser.getToolpath();
// Use for 3D rendering or simulation

3. Check Bounds Before Machining

javascript
const bounds = report.stats.bounds;
if (bounds.x.max > 50 || bounds.z.min < -30) {
  console.warn('Part exceeds machine limits!');
}

4. Validate Feed Rates

javascript
report.commands.forEach(cmd => {
  if (cmd.feedRate && cmd.feedRate < 10) {
    console.warn(`Slow feed at line ${cmd.lineNumber}`);
  }
});

5. Track Tool Changes

javascript
const toolChanges = parser.getToolChanges();
const tools = new Set(toolChanges.map(tc => tc.tool));
console.log(`Tools used: ${Array.from(tools).join(', ')}`);

Common Issues:

Q: Why is my arc not working? A: Arc needs I/K offsets OR R radius. Add one of: G2 X10 Z10 I5 K0 or G2 X10 Z10 R7.071

Q: How do I get final position? A: Access parser.state.position after parsing.

Q: How do I extract just motion? A: Use parser.getToolpath() to get RAPID, LINEAR, and ARC commands only.
